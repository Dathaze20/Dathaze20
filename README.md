# Abel Arroyo

**Mobile-First Software Builder**

I build software around real problems I want solved — Android apps, PWAs, browser media tools, AI-assisted workflows, and hardware integrations.

My projects range from a local-first Android music player tested against a 15,000-song library to turning an Android phone into a real Bluetooth HID gamepad.

## Featured Projects

### 🎵 [My Music — Smart Music Player](https://github.com/Dathaze20/Music-Player-Tagger)

A local-first Android music player with native metadata editing, AI-assisted auto-tagging, MediaStore integration, background playback, lyrics, playlists, EQ, backup/restore, WiFi sharing, and support for large music libraries.

**Built with:** JavaScript · Capacitor · Native Java · Android MediaStore · MusicBrainz · Gemini

---

### 🎮 [PocketPad](https://github.com/Dathaze20/PocketPad)

Turns an Android phone into a real Bluetooth HID gamepad for TVs, tablets, phones, and PCs. Includes touch controls, multiple controller layouts, haptics, reconnect support, and physical-controller passthrough.

**Built with:** Kotlin · Android Bluetooth HID · USB HID · Custom Android UI

---

### 🎬 [Audio to YouTube MP4](https://github.com/Dathaze20/AUDIO-TO-YOUTUBE-MP4)

A mobile-first browser tool that combines an audio file and cover image into a YouTube-ready video without uploading the user's media to a server.

**Built with:** React · TypeScript · Vite · Canvas · Web Audio · MediaRecorder · Vitest · GitHub Actions

**Live app:** https://dathaze20.github.io/AUDIO-TO-YOUTUBE-MP4/

---

### 🏓 [Super Pong](https://github.com/Dathaze20/Pong-Game-)

A heavily expanded mobile Pong game with four game modes, custom player photos, user-selected music, achievements, persistent stats, Hall of Fame, themes, power-ups, synthesized Web Audio effects, local multiplayer, AI difficulty levels, and PWA installation.

**Built with:** JavaScript · HTML5 Canvas · Web Audio · PWA APIs · Vitest · ESLint

---

### 🔨 [Forge](https://github.com/Dathaze20/Forge)

A mobile-first PWA built around my own long-form writing workflow. It turns research notes and a point of view into structured article drafts using Gemini while keeping the interface simple enough to use from a phone.

**Built with:** React · TypeScript · Vite · Gemini API · PWA APIs

## How I Build

I am product-driven first: identify a real problem, build the smallest useful version, test it on actual devices and real data, then keep iterating until it is dependable enough to use.

I use AI-assisted development as part of that workflow, but the engineering work still includes architecture decisions, debugging, device testing, API integration, release automation, and maintaining the finished product.

---

## Current Focus

- Shipping and maintaining useful mobile-first software
- Android and browser capabilities that normally require separate apps or hardware
- Local-first tools that keep user files on-device whenever practical
- Better testing, architecture, release engineering, and maintainability with every project
